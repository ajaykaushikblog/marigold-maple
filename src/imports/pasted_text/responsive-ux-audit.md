PHASE 10 — RESPONSIVE DESIGN + MOBILE UX AUDIT

Keep the existing website design, design system, components, CMS architecture, routes, content models, SEO system, advertisement system, Pinterest system, and all existing functionality.

DO NOT redesign the website from scratch.

This phase is a complete responsive UX pass across the entire Universal Lifestyle CMS.

The goal is to make the website work professionally across mobile, tablet, laptop and large desktop screens before continuing with the CMS/admin system.

==================================================
1. RESPONSIVE BREAKPOINT SYSTEM
==================================================

Mobile:
320px
375px

Avoid unnecessary breakpoint-specific duplication.

Use fluid sizing where appropriate.

==================================================
2. GLOBAL RESPONSIVE HEADER
==================================================

Audit the global header.

Desktop:
- Logo
- Primary navigation
- Category/occasion navigation
- Search
- Subscribe
- Appropriate spacing

Tablet:
- Simplified navigation where necessary
- Search remains accessible
- No horizontal overflow

Mobile:
- Logo
- Search
- Menu button
- Subscribe where appropriate

Create a clean mobile navigation drawer/menu.

Mobile navigation should support:

Occasions
Life Events
Food & Recipes
Beauty
DIY & Crafts
Home & Decor
Gifts
Ideas & Advice

Allow expandable navigation groups.

Do not allow the navigation to exceed viewport width.

==================================================
3. HOMEPAGE RESPONSIVE AUDIT
==================================================

Audit every homepage section.

Desktop:
- Editorial hero
- Multi-column content grids
- Seasonal sections
- Category sections
- Newsletter
- Advertisements

Tablet:
- Reduce columns intelligently
- Maintain image hierarchy
- Preserve readable typography

Mobile:
- Single-column or carefully controlled two-column layouts
- Large featured story
- Horizontal scrolling only where intentionally designed
- No accidental horizontal overflow
- Comfortable spacing
- Images remain prominent

Do not simply shrink the desktop layout.

Recompose sections where necessary.

15. MOBILE STICKY ELEMENTS
==================================================

Audit all sticky elements.

If using:

- Sticky header
- Sticky share controls
- Sticky recipe controls
- Sticky advertisements

Ensure they do not stack on top of each other.

Nothing should cover article content.

Do not create excessive sticky UI.

==================================================
16. HORIZONTAL OVERFLOW AUDIT
==================================================

Search the entire application for accidental horizontal scrolling.

Fix overflow caused by:

- Long titles
- Images
- Buttons
- Navigation
- Cards
- Tables
- Filters
- Ads
- Pinterest images
- Social buttons
- Code/data blocks

The normal page should not horizontally scroll on mobile.

20. ACCESSIBILITY
==================================================

Perform a responsive accessibility pass.

Check:

- Keyboard focus
- Visible focus states
- Semantic buttons
- Accessible labels
- Form labels
- Color contrast
- Heading hierarchy
- Image alt text
- Mobile menu accessibility
- Dialog/overlay accessibility
- Screen reader labels

Do not rely on color alone to communicate state.

==================================================
21. PERFORMANCE-FRIENDLY RESPONSIVE DESIGN
==================================================

Keep responsive implementation lightweight.

Avoid:

- Large unnecessary JavaScript
- Duplicate desktop/mobile content
- Heavy animations
- Layout-shifting elements
- Unnecessary third-party scripts

Prefer CSS responsive behavior and reusable components.
