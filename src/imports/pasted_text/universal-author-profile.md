PHASE 6 — CREATE THE UNIVERSAL AUTHOR PROFILE PAGE

The following public pages are already completed:

1. Homepage
2. Universal Category Page
3. Universal Article Page
4. Universal Recipe Page
5. Universal DIY / Tutorial Page

Do NOT redesign or modify those pages.

Keep the exact existing design system:
- typography
- colors
- spacing
- header
- footer
- cards
- image treatment
- badges
- newsletter
- advertisements
- responsive behavior

Now create the UNIVERSAL AUTHOR PROFILE PAGE.

This must be a reusable author template for every writer, creator, editor, photographer, recipe developer, designer, or contributor on the website.

Do NOT design this specifically for one person.
